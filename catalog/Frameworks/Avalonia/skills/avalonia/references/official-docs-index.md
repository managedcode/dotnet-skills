# Official Avalonia documentation map

Use the documentation for the installed major: [Avalonia 12](https://docs.avaloniaui.net/docs/welcome), [Avalonia 11](https://v11.docs.avaloniaui.net/), and the [12 breaking changes](https://docs.avaloniaui.net/docs/avalonia12-breaking-changes). Version 12 desktop requires .NET 8 or later and recommends .NET 10; mobile requires .NET 10. Resolve actual package support from the installed version and its release notes.
